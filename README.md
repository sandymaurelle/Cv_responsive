# Portfolio Personnel Responsive

## Présentation du projet

Ce projet consiste en la création d’un portfolio personnel responsive développé avec HTML5, CSS3, Bootstrap 5 et JavaScript.

L’objectif est de présenter mon profil, mes compétences, ma formation et mes projets à travers une interface moderne et responsive tout en appliquant les notions vues dans le cours.

Le site est entièrement responsive et s’adapte aux écrans d’ordinateur, tablette et mobile.

# Fonctionnalités

- Barre de navigation responsive
- Navigation fluide entre les sections
- Section d’accueil (Hero section)
- Section About Me
- Section Skills
- Section Languages
- Section Education avec accordéon Bootstrap
- Section Projects
- Section Contact
- Bouton de téléchargement du CV
- Animations au scroll
- Effet typing en JavaScript
- Bouton retour en haut
- Utilisation du système de grille Bootstrap
- Design moderne avec effet glassmorphism
